POD Admin Dashboard

Import delivery form

CSV or Excel. One file per lorry.
  1. Export the shipment from your system as CSV or Excel (.xlsx).
  2. Press Choose file and pick it. One file per lorry.
  3. The invoices must add up to the form total. If they do not, nothing is imported and the message shows the difference.
  4. If the lorry or the route already has a shipment that day, you are asked: add a 2nd trip or 2nd lorry, replace, or cancel.
Branch—

Shipments

  1. Crew: type a staff ID or a name, pick the person, then press Save crew. A driver is required, a helper is optional.
  2. Salesman delivery: type the salesman in the Driver box and pick him. An office sign-in is asked the first time.
  3. Print invoices opens the combination invoices of that lorry. Print all invoices opens every lorry of this date.
  4. Delete shipment removes the card and its invoice rows. It cannot be undone. Delivered photo records are kept.
